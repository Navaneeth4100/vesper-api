# Vesper AI — Next-Gen API Workbench & Edge Mock Engine

Vesper AI is an AI-native API Workbench and Mock Engine that converts OpenAPI specs, GraphQL schemas, or plain natural language prompts into instant, zero-latency edge mock servers and automated contract tests.

## 🚀 Features

- **Interactive API Workbench**: Test endpoint routes (`POST`, `GET`, `PUT`), adjust simulated edge latencies, and pick HTTP status codes (`200 OK`, `429 Rate Limit`, `500 Server Error`).
- **Prompt-to-Mock Engine**: Switch between prompt presets (Stripe Webhooks, OAuth2 tokens, IoT nodes) to generate TypeScript contracts and synthetic JSON responses.
- **Global Edge Architecture Benchmarks**: Visual chart demonstrating sub-15ms WASM edge routing vs. traditional cloud servers.
- **Obsidian Dark-Mode Aesthetic**: High-contrast glassmorphism (`backdrop-filter: blur(20px)`), neon violet/cyan glow accents, and responsive typography (Inter & JetBrains Mono).
- **Honest Developer Pledge**: Zero fabricated testimonials, zero fake user counts, zero fake client logos.

## 🛠️ Quick Start

This project is built with zero framework overhead (HTML5, CSS3, Vanilla JS).

Simply open `index.html` in any web browser, or serve locally with any HTTP server:

```bash
# Using Python
python -m http.server 8000

# Or using npx serve
npx serve .
```
